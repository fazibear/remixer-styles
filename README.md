# ReMixer Styles

Styles and assets for [ReMixer](https://remixer.fazibear.me).
ReMixer itself is closed source; this repository contains its styles only.

Each style directory contains `style.yaml` and its referenced images and fonts.
Keep asset license files with their styles.

## Use a style

Visit the [ReMixer website](https://remixer.fazibear.me) to preview styles and
install ReMixer and styles through ReaPack.

To customize a style, copy its directory into your ReMixer Styles folder,
edit `style.yaml` or its assets, and choose **Refresh** in ReMixer.
